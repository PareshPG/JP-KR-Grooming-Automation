
# Monthly Excel Automation

## Project Overview
Python-based automation for monthly survey
data processing and Excel workbook maintenance.

## Main Modules
1. IDxAGE Builder
2. Table Two Deduplication
3. Safe Excel Writer
4. Respondent Data Validation

## Technologies
- Python
- OpenPyXL
- Pandas
- VS Code
- Git

## Purpose
Automate repetitive Excel processing,
reduce manual errors and preserve workbook
structures.

## Version Control
Source code backed up using GitHub.
